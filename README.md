# Скриншотер (Screenshoter) v5.1

Программа для скриншотов под Windows в духе Lightshot: выделяете область, рисуете поверх, копируете или сохраняете. Тёмный современный интерфейс, Python + Tkinter. Free software (свободное ПО), 2026.

## Установка и запуск

1. Нужен Python 3.9+ (при установке отметьте «Add Python to PATH»).
2. `install.bat` — установит Pillow, pystray, pynput.
3. `run.bat` — запуск, в трее появится значок; снимок — клавиша **PrtScn**.
4. `build_exe.bat` — сборка одного `.exe` через PyInstaller (результат в папке `dist`).

Автозапуск: правый клик по значку в трее → «Запускать вместе с Windows».

> В Windows 11 PrtScn по умолчанию открывает «Ножницы». Отключите: Параметры → Специальные возможности → Клавиатура → «Использовать клавишу Print Screen для открытия функции снимка экрана».

## Возможности

- Пропорции рамки: свободно, 1:1, 4:5, 3:4, 4:3, 16:9, 9:16, 3:2, 2:3, своё соотношение или точный размер; положение рамки запоминается.
- Рисование: карандаш (со скруглением), линия, кривая по 3 точкам, стрелка, прямоугольник, круг/эллипс; цвет, прозрачность, толщина; отмена и повтор.
- Курсор мыши можно включить в снимок; плюсик-курсор показывается только во время рисования.
- Быстрое сохранение и «Сохранить как…» с выбором формата (PNG, JPG, WEBP, BMP) и качества.
- Режим «Снимок при сохранении»: экран не замораживается, снимок делается в момент сохранения (второй PrtScn тоже сохраняет и закрывает).
- Режим коллажа: живой экран, кадры с подписями «Скриншот N» и чёрными разделителями, затемнение вне рамки (настраивается).
- Окно «Настройки»: формат, качество, затемнение, режим снимка при сохранении, горячие клавиши и сведения о программе.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| PrtScn | Сделать скриншот; второе нажатие — сохранить и закрыть |
| Esc | Выход |
| Enter / Ctrl+C | Копировать в буфер обмена |
| Ctrl+S / Ctrl+Shift+S | Сохранить / Сохранить как… |
| Ctrl+A | Выделить весь экран |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Стрелки (Shift — ×10) | Сдвиг рамки |
| V, P, L, C, A, R, O | Перемещение (повторно — отжать), карандаш, линия, кривая, стрелка, прямоугольник, круг |
| S | Скругление карандаша |
| `[` и `]` | Толщина |
| 0 … 8 | Пропорции рамки |
| Shift при рисовании | Шаг 15° / квадрат / ровный круг |
